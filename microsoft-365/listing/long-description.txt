Glide is an agent for Microsoft 365 Copilot. It connects Copilot to your GlideOS workspace, so teams that build and run business apps on Glide can manage them from Copilot. Ask Copilot to create and manage projects, query and modify app databases, run workflows, publish and roll back apps, and read, write, and search project files.

For example, ask: "Which of my Glide projects have a database, and what tables are in them?"

Every request runs as you, inside your Glide organization, with your role (admin, editor, or viewer). Copilot can only reach the projects, apps, and data you can open yourself.

What you can do
- Projects: list, search, create, rename, and delete projects.
- Apps: publish, promote, and roll back versions; set who can open an app; manage vanity subdomains and custom domains; read build and runtime errors.
- Data: list tables, run read-only queries, run SQL, load CSV, JSON, or XLSX data into a table, and create, list, and restore backups.
- Files: read, write, edit, search, copy, move, and restore project files.
- Workflows: run workflows on demand, inspect runs, and manage schedules, webhooks, and app triggers.
- Integrations: find integration tools and enable event triggers that start workflows.
- Diagnostics: query debug logs, list AI models, check AI usage, and review the audit log of tool calls.

Access requires a Glide account on a plan that includes the MCP server feature. Sign in with your Glide account when Copilot prompts you; no API keys are needed. New to Glide? Sign up at glideapps.com.

Responses are generated by AI in Microsoft 365 Copilot and can be wrong. Review what the agent proposes before you confirm a change.
